[008 source, lines 4239–4258 and 4392–4490](evidence/editor-source/ai-research-collection-20260921T030437Z-f7d8e930/008-LanceStatusWidget-source.COPY).

## Qualifications for the implementing task

**Lifecycle invalidation cannot rely solely on ControllerConfigured.** The report's source-lead wording at control analysis line 23 and the observer handoff's polling caveat at line 27 are appropriately cautious. More specifically, HandleMechBindings' new-pawn IsValid macro has only its valid execution output connected (010 lines 5050–5059). A null/unpossessed pawn therefore does not reach this function's new-component notification path. The failed new-mech cast only enters the spectator branch when IsMultiplayerClient is false (4952–4964, 4997–5005). The ordinary component callback is downstream of a successful new-mech cast; the spectator callback is downstream of its own successful cast (4783–4795, 4828–4840, 5070–5095). This is not evidence those transitions never generate another notification elsewhere. The proposed immediate invalidation requirement needs its own proven event coverage; polling at 2 Hz cannot itself prove immediate delivery. Include null pawn/unpossess and mission transition explicitly in the supervised probe. [010 source](evidence/editor-source/ai-research-collection-20260921T030437Z-f7d8e930/010-MW5PlayerController-source.COPY).

**Factory deduplication is only demonstrated within one invocation.** Control analysis line 25 accurately describes the Contains check, but a future implementer must not read it as repeat-call idempotence. Entry executes Array_Clear(RuntimeControllerComponents) first, then scans the registry (010 lines 1456–1465, 1589–1595). Classes are appended after AddComponentByClass and compared against that newly cleared list (1466–1501, 1604–1621). The graph does not inspect existing components before adding them, and its subsequent enumeration serves configuration notifications. Whether AddComponentByClass independently prevents duplicates is native and unavailable here. Avoid repeatedly invoking this factory as a speculative startup repair; prove single creation and stable component count across mission/pawn transitions. [010 source](evidence/editor-source/ai-research-collection-20260921T030437Z-f7d8e930/010-MW5PlayerController-source.COPY).

Neither qualification blocks the offline report or handoff. Both remain unresolved implementation/measurement obligations before live autonomy. The reviewed documents already preserve the required artifact manifest, disposable Instant Action test, rollback, human precedence and no-deployment boundary.
