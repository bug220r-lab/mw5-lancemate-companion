Therefore this follow-up makes an installation proposal concrete but does **not** establish that installation is ready on this machine. The game remains on Steam; Epic is the official editor distribution channel. [E01, E02, E09]

The next useful information is a read-only Epic install-dialog readout showing this exact Mercenaries product, entitlement/access, destination, download size, and required disk space, without pressing Install or accepting new terms. ## What even a plausible editor match would not establish

A matching UE major/minor or plausible PGI content version is only a prerequisite. It would not prove exact retail ABI compatibility, editable access to every asset, complete proprietary C++ source, availability of a compatible native plugin toolchain, permission for process injection, shipped Blueprint networking/file I/O nodes, a usable bidirectional external bridge, correct host authority for order dispatch, or packaged runtime acceptance of a specific lancemate command. Those require the later scoped asset/node inspection, licence/API review and isolated packaged runtime evidence already identified in the sprint. A successful editor-only preview cannot substitute for that evidence. [E03, E04, E06–E08]
