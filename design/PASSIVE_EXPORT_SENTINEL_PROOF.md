The expected payload is **30 ASCII bytes**, hex `4D57355F504153534956455F4558504F52545F53454E54494E454C5F5631`, SHA-256 `dd9128ff19e9676c8518033b6cc119d4a6352352edbf4ea8dc444ea28bbebe1a`. Absence or False is a failed/unknown writer route, not evidence about observer creation. File timestamps alone are insufficient.

Stop for input interference, unexpected controller/world, invalid or truncated Phase B evidence, compilation/cook error, crash, resource gate failure, unexpected file creation or any write outside the pinned directory. Preserve failure artifacts; do not try another directory, enable append/overwrite, or loop until success. After the attempt, remove only manifest-listed temporary control files while the game is closed, restore the recorded enabled-mod state only after checking for intervening user changes, verify original observer hashes, and retain the disposable output as evidence.
